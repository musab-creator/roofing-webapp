# Project Skills

Skills in this directory are loaded automatically by Claude Code for this project.

## ui-ux-pro-max-skill

The `banner-design`, `brand`, `design`, `design-system`, `slides`, `ui-styling`,
and `ui-ux-pro-max` skills are vendored from the
[ui-ux-pro-max-skill](https://github.com/musab-creator/ui-ux-pro-max-skill)
package (v2.11.0), licensed MIT (Copyright (c) 2024 Next Level Builder).

They provide UI/UX design intelligence — a searchable database of styles, color
palettes, font pairings, UX guidelines, and stack-specific patterns — plus
supporting skills for design systems, branding, and presentations.

To update, re-vendor the `.claude/skills/` contents from the upstream repository.
